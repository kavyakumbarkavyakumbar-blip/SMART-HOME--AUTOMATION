# Smart Home Automation System

## Overview

This project demonstrates a Smart Home Automation System developed using Embedded C and 8051 Microcontroller. The system controls electrical appliances through UART serial communication by receiving commands from a Bluetooth module or serial terminal.


## Objective

To design and implement a wireless appliance control system using Embedded C and UART communication.


## Features

* Wireless appliance ON/OFF control
* UART serial communication
* Embedded C based implementation
* Real-time device operation
* Relay interfacing for appliance control

## Technologies Used

* Embedded C
* 8051 Microcontroller
* UART Protocol
* Serial Communication

## Hardware Components

* 8051 Microcontroller
* Relay Module
* Bluetooth Module (HC-05)
* Power Supply
* Connecting Wires

## Software Used

* Keil uVision
* Proteus Simulation
* Embedded C

## Working Principle

The microcontroller receives serial commands through UART communication. Based on the received input:

* `'1'` → Turns ON the appliance
* `'0'` → Turns OFF the appliance

The relay module acts as a switch to control the connected device.
